# bundesliga-fantasy-manager-assistant
Analyzes Bundesliga player data, in order to make recommendations to someone using the [Bundesliga Fantasy Manager](https://fantasy.bundesliga.com/) application.

**Contents**

- [Development environment](#development-environment)
- [License](#license)


## Development environment

I use [uv](https://docs.astral.sh/uv/) to:

- Manage the installation of Python interpreters.
- Create a Python virtual environment.
- Manage Python package dependencies.
